DUPLICATE-KEY PROTECTION

CrowRules Admin v2.4 avoids blind inserts for records that contain unique identifiers. The application first attempts to locate an existing record and uses an update path where appropriate instead of creating another record with the same unique value.

Database-level UNIQUE constraints and Supabase RLS should remain the final protection against duplicate records.
