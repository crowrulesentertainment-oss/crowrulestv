INDEPENDENT BROADCAST REQUIREMENTS

One process per channel

For four simultaneous streams, the playout service must run four isolated channel workers. Each worker needs its own playlist cursor, schedule runner, encoder process, destination credentials, heartbeat and restart policy. A single OBS instance or one shared stream output cannot broadcast four independent channels by itself.

DEPLOYMENT NOTES

What is required for 24/7 broadcasts?

  1. Apply crowrules-plus-schema.sql in the Supabase SQL Editor.
  2. Sign in with a Supabase Auth account and initialize the four network channels.
  3. Deploy the CrowRules+ Node.js playout bridge on an always-on host.
  4. Run one isolated worker and encoder output per enabled channel.
  5. Store YouTube stream keys on the server, never in GitHub Pages or browser storage.
  6. Test each channel independently before enabling unattended 24/7 automation.
TACOMA NIGHTS PROTECTION

Separate system, preserved production

This studio uses its own cr_ database tables and a new studio path in the CrowRules TV repository. It does not edit or replace the Tacoma Nights Studio files, existing queue, bridge routes or production tables.
